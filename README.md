# Tindahan Ko

A simple stock, sales and profit tracker for a small store (vegetables and canned goods to start).
It runs entirely in the browser: no account, no server. All store data stays on the device it is used on.

- Works offline once opened, and can be added to a phone's home screen.
- Optional 4-digit PIN lock.
- Backup file (restorable) and spreadsheet (CSV) downloads in Settings.

Use **Settings > Download backup** regularly. Data lives only in this browser on this device.
